# continue-hook

Do not end a turn by asking whether you should do something you were already
able to do. Finish it, then report: **result + verification + remaining risks**.

Ask only when the decision is genuinely the user's: spending money, real-name
identity, publishing externally, deleting or overwriting data, changing shared
systems, or information only the user has. Then ask in one short line and stop.

Full rule: `skills/continue-hook/SKILL.md`.
